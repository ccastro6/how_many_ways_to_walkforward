released under the SIL Open Font License 1.1 (https://openfontlicense.org), which
permits redistribution with documents and software.

- Source Sans Pro (Adobe), copied from TeX Live `fonts/opentype/adobe/sourcesanspro`.
- STIX Two Text (STI Pub Companies), copied from TeX Live `fonts/opentype/public/stix2-otf`.
